Allows to have a Sub Tab Menu UI so one Main Tab can have multiple sub Tabs. This is currently designed for the Vertical Tab Menu.

To Add you need to do the following:
1. Go to the Tab Switcher on your Vertical Tab Menu
2. Under Tab Adjustment replace the Tab Prefab with with Sub Tab Menu Page
3. Then Press "Add Tab"

After this you should be done, if you want to add more normal Tabs don't forget to change the prefab back.
If you have added such a Tab adding more Tabs might be a bit difficult, so please post a message on the Discord if you need help!
