# What is Modern UIs?

<img width="2048" height="1536" alt="Thumbnail" src="https://github.com/user-attachments/assets/5909f78f-f3a2-4106-8656-eda7b400d5e7" />

Modern UIs is a collection of prefabs, scripts, and UI elements designed to help creators build clean, modern-looking interfaces and permission systems for VRChat worlds.

It focuses on making UI development easier through modular and flexible components while maintaining a polished, modern appearance. The included systems are designed to be easy to integrate and customize for different world setups.

## Core Features

* Modular prefabs for fast and flexible UI building
* Built-in permission systems with support for third-party integrations, including:
  * [VRCLinking](https://github.com/DrBlackRat/VRC-ModernUIs-Integration-VRCLinking)
  * [DisBridge](https://github.com/DrBlackRat/VRC-ModernUIs-Integration-DisBridge)
  * [AccessTXL](https://github.com/DrBlackRat/VRC-ModernUIs-Integration-VRCLinking)
* Support for VRChat's Creator Economy
* Smooth, animation-driven transitions and feedback
* Customizable UI color themes
* Included icons, sprites, sound effects, and other resources
* Designed for clarity, usability, and a modern aesthetic
* Easy to integrate and customize for different world setups

# How to use it

Modern UIs includes a collection of prefabs, scripts, themes, and other resources that you can use in your own world.

### Example Scene

If you're just getting started, I highly recommend checking out the included demo scene first!

You can open it in Unity under:

`Tools > DrBlackRat > ModernUIs`

The scene showcases different features and examples of how the included components and systems work together. It should give you a good starting point for understanding how everything is set up.

### Finding the included assets

You can find all the included assets directly through the Unity menu:

* **Prefabs:** `Tools > DrBlackRat > ModernUIs > Show Prefabs Folder`
* **Scripts:** `Tools > DrBlackRat > ModernUIs > Show Scripts Folder`
* **Themes:** `Tools > DrBlackRat > ModernUIs > Show Themes Folder`
* **Resources:** `Tools > DrBlackRat > ModernUIs > Show Resources Folder`

The Themes folder contains the available UI color themes, while the Resources folder contains things like icons, sprites, sound effects, and other shared resources.

# Important

**Do not add your own files inside the Modern UIs folder!**

This includes prefabs, scripts, themes, resources, and any other assets you create.

The Modern UIs will be replaced or modified when installing updates. Anything you add inside it could get lost in the process.

Keep your own files somewhere else in your Unity project to avoid losing them when updating Modern UIs.
