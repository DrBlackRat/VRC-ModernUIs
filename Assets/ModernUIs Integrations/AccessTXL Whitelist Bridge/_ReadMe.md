Version 0.2.0

Allows importing & exporting Access TXL to Modern UI Whitelists.

Requirements:
- ModernUIs V0.10.0 or newer
- AccessTXL V1.2.4 or newer

Access TXL To Whitelist Setup:
1. Grab the "Access TXL to Whitelist Bridge" Prefab out of the Prefabs folder and drag into your scene.
2. Assign the Access Control you want to use as a Whitelist to it.

Whitelist to Access TXL Setup:
1. Grab the "Whitelist to Access TXL Bridge" Prefab out of the Prefabs folder and drag into your scene.
2. Assign the Whitelist you want to use for Access Control to it.
3. On your Access Control enable "Allow Whitelist".
4. Drag the "Whitelist to Access TXL Bridge" Game Object into your Access Control as a whitelist source.
