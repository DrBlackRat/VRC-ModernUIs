Version 0.2.0

Allows importing VRC Linking to Modern UI Whitelists.

Requirements:
- ModernUIs V0.10.0 or newer
- VRCLinking SDK V0.1.9 or newer

Setup:
1. Grab the Prefab you need out of the Prefabs folder and drag into your scene.
2. Assign the Discord Role IDs or Role Names you want to be on the Whitelist.
3. Assign the VRChat Group Role IDs or Role Names you want to be on the Whitelist.
